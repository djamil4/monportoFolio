# Mon Portfolio Créatif

Ce dépôt contient le site portfolio statique de Ajmal IMOROU.

## Contenu

- `monportoFolio.html` : page principale
- `monportoFolio.css` : styles du site
- `Images/` : image de profil
- `tunnel de vente/` : page de tunnel de vente

## Exécution locale

Ouvre `monportoFolio.html` dans ton navigateur pour voir le site.

## Déploiement GitHub Pages

1. Crée un dépôt GitHub.
2. Ajoute l'URL du dépôt en remote.
3. Pousse la branche `main`.
4. Active GitHub Pages sur la branche `main` et le dossier `/ (root)`.

Le site sera ensuite accessible via `https://TON_UTILISATEUR.github.io/monportoFolio`.
